# Security Policy

## Reporting a vulnerability

This is a local, unpublished candidate. Its public security-reporting channel is not active yet.
The site must not be deployed until the corporate mailbox, account recovery, domain authentication,
and an incident-response owner have been verified.

The verified private reporting channel and response target will be published here before launch.

## Scope

This repository contains a static website only. It holds no user data, no backend and no
credentials. Future reports will cover the site's headers, content-security policy, and CI pipeline
without exposing internal systems.

Images, fonts, posters, and video loops are self-hosted. The multimedia module does not request
remote streams, analytics, maps, telemetry, accounts, or third-party players.
